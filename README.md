# SQL Sales Analysis Project

This project presents a sales data analysis using Microsoft SQL Server and SQL queries.

The goal was to analyze customer purchases, product performance and revenue metrics using relational data.

---

## Dataset

The dataset includes three tables:

- customers — customer information (region, age)
- products — product catalog with categories and prices
- sales — transaction data with units and dates

---

## Tools Used

- Microsoft SQL Server
- SQL Server Management Studio
- GitHub

---

## SQL Skills Demonstrated

- SELECT, WHERE
- GROUP BY, ORDER BY
- Aggregations (SUM, AVG, COUNT)
- INNER JOIN
- Revenue calculations
- Business question analysis
- Subqueries

---

## Analysis Steps

### 1️⃣ Database structure
- created relational tables
- defined keys and relationships

### 2️⃣ Basic queries
- filtering customers
- counting records
- average age

### 3️⃣ Joins & revenue analysis
- joined sales + customers + products
- calculated transaction revenue
- revenue by category and region

### 4️⃣ Business questions
Answered questions such as:

- Who are the top 5 customers by revenue?
- Which categories generate the most revenue?
- What is the average order value?
- Which region performs best?
- Which products sell the most units?
